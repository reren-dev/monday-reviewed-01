Entry for make.fun's [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) bounty ($2 in USDC).

## The review

> Monday gave me 47 unread emails before 9 a.m., a 'quick sync' that ran 47 minutes, and coffee that went cold in solidarity — one star, and only because zero stars isn't an option.

## How it works

`main.py` (Python 3.13, stdlib only, no network, no wall clock) writes the
one-line Monday review to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The program
validates the review against the competition gate first: 1–200 characters,
a single line, not only whitespace. Two runs produce byte-identical output.
